## 3. macOS Splits Device Control and Full Disk Access: What Mac Apps Must Handle

- **Why now:** Apple's **November 16, 2026** developer news item "Updates to Device Control
  and Data Access, and Full Disk Access in macOS" (<https://developer.apple.com/news/>)
  splits Device Control and Data Access into **System & App Protection Override** and
  **Accessibility**. Apps using Full Disk Access for backup, or Accessibility for assistive
  technology, can request entitlements **for new installations**; existing user permissions
  stay in effect.
- **Reader value:** The practical read for anyone shipping a Mac utility, backup tool or
  dev-tool helper: degrade gracefully when folder or app access is denied, decide whether
  you need the entitlement, and stop treating Full Disk Access as a given for new users.
  Pairs naturally with the Developer ID certificate work.
- **Target phrase:** "macos full disk access entitlement"

  `unstable_cache()` (GHSA-mfr8-8qww-v76h), cache leak across root param values in nested

- **Reader value:** A multi-tenant audit for small Next.js backends: where root params and

## 5. Android 17 Delays WebOTP Codes by Three Hours: Fix Your Phone Auth

- **Why now:** Android 17 (API 37) extends SMS one-time-password protection to the
  **WebOTP** format for **all apps regardless of target SDK**
  (<https://developer.android.com/about/versions/17/behavior-changes-all>). If an app can
  read SMS but is not the domain-verified intended recipient, the message is withheld for
  **three hours** — `SMS_RECEIVED_ACTION` broadcasts withheld, SMS provider queries
  filtered. Apps targeting API 37 get the same protection on standard SMS. Google's
  guidance: move to **SMS Retriever** or **SMS User Consent**.
- **Reader value:** Phone-number login is the quiet breakage here — anyone auto-reading
  codes outside domain verification sees OTP autofill stop working with no exception
  thrown. What to change, how domain verification decides it, and the migration path. Same
  page also lands app memory limits, a 50,000 per-app keystore cap and blocked cross-profile
  loopback traffic, which make good secondary sections.
- **Target phrase:** "android 17 sms otp webotp"
